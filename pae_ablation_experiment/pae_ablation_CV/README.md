# PAE Ablation Experiment

Measures the contribution of PAE (Predicted Aligned Error) features to t2pmhc model performance using 5-fold stratified cross-validation.

## Conditions

| Condition | Model | PAE Features | input_dim | edge_dim (GAT) |
|-----------|-------|-------------|-----------|----------------|
| GAT + PAE | t2pmhc-GAT | All features | 33 | 2 |
| GAT - PAE | t2pmhc-GAT | PAE ablated | 31 | 1 |
| GCN + PAE | t2pmhc-GCN | All features | 33 | - |
| GCN - PAE | t2pmhc-GCN | PAE ablated | 31 | - |

## PAE Features Ablated

1. **Node: PAE** (global structure PAE) - 1 dimension
2. **Node: PAE_TCRpMHC** (TCR-pMHC specific PAE) - 1 dimension
3. **Edge: PAE** (per-edge PAE values, GAT only) - 1 dimension

## Running

### Prerequisites
- Branch `pae_ablation` must be checked out and installed (`pip install -e .`)
- Graph `.pt` files for GAT and GCN at distance threshold 10A
- Update `<PLACEHOLDER_GAT_GRAPHS>` and `<PLACEHOLDER_GCN_GRAPHS>` in SLURM scripts

### Submit jobs
```bash
sbatch scripts/slurm/gat_with_pae.submit
sbatch scripts/slurm/gat_no_pae.submit
sbatch scripts/slurm/gcn_with_pae.submit
sbatch scripts/slurm/gcn_no_pae.submit
```

### Resume after timeout
Simply resubmit the same script. The checkpoint/resume logic:
- Completed folds (final `.pt` exists) are skipped
- Partially-trained folds resume from the last epoch checkpoint
- Unstarted folds train from scratch

### Analyse results
```bash
python scripts/analyse_pae_ablation.py
```
